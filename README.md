# Afan Shafiq Portfolio

A polished, animated portfolio website for **Afan Shafiq**, positioned as a Machine Learning Expert and AI Engineer. The site is built with lightweight HTML, CSS, and JavaScript so it can be deployed to any static host without installing external dependencies.

## Highlights

- Premium AI-themed hero section with animated neural visuals, glowing glass cards, and floating badges.
- Responsive sections for expertise, projects, process, skills, and contact.
- Smooth scrolling, scroll progress indicator, mobile navigation, animated marquee, and reduced-motion support.
- Zero third-party runtime dependencies.

## Run Locally

```bash
npm start
```

Open `http://localhost:4173`.

## Check & Build

```bash
npm run check
npm run build
```

The build command copies publishable assets to `dist/`.
